# 🎛️ DroneControl - Единый UI Интерфейс

## ✅ **ЗАДАЧА ВЫПОЛНЕНА!**

Весь интерфейс объединен в **один файл `UI_HUD.ui`** для удобного редактирования в Qt Designer.

## 📁 **Структура проекта:**

```
test-project/
├── main.py                 # 🚀 Основной файл приложения  
├── mavlink_connection.py   # 📡 MAVLink соединение
├── UI_HUD.ui              # 🎨 ЕДИНЫЙ UI ФАЙЛ (все элементы)
├── requirements.txt       # 📦 Зависимости Python
├── build_exe.bat         # 🔨 Сборка .exe файла
└── run.bat               # ▶️ Запуск приложения
```

## 🎨 **Что содержит UI_HUD.ui:**

### 📍 **Левая панель - Телеметрия:**
- `connectionStatusButton` - Индикатор подключения
- `coordinatesLabel` - Координаты GPS  
- `altitudeLabel` - Высота полета
- `speedLabel` - Скорость движения
- `batteryLabel` - Уровень батареи
- `batteryProgressBar` - Прогресс-бар батареи
- `batteryModeButton` - Переключение % ↔ V
- `modeLabel` - Режим полета
- `armedLabel` - Статус вооружения
- `gpsLabel` - Количество GPS спутников

### 🚁 **Центральная панель - Управление дронами:**
- **Группа подключения MAVLink:**
  - `protocolCombo` - Выбор протокола (TCP/UDP)
  - `hostInput` - IP адрес
  - `portInput` - Порт
  - `missionPlannerButton` - Пресет Mission Planner
  - `sitlButton` - Пресет SITL
- **Кнопки подключения:**
  - `stopButton` - Подключить
  - `connectButton` - Отключить  
  - `startButton` - Быстрое подключение
- **Список дронов:**
  - `dronesListWidget` - Список подключенных дронов
- **Управление:**
  - `armButton` - ARM (вооружить)
  - `disarmButton` - DISARM (разоружить)

### 📝 **Правая панель - Логи:**
- `logsTextEdit` - Область отображения логов

### 🔧 **Нижняя панель - Статус:**
- `settingsButton` - Кнопка настроек
- Область статуса системы

## 🚀 **Как использовать:**

### 1. **Запуск приложения:**
```bash
python main.py
# или
run.bat
```

### 2. **Редактирование интерфейса:**
```bash
# Откройте UI_HUD.ui в Qt Designer
designer UI_HUD.ui
```

### 3. **Сборка .exe:**
```bash
build_exe.bat
```

## 🎯 **Преимущества единого UI:**

✅ **Все элементы в одном месте**  
✅ **Легко редактировать в Qt Designer**  
✅ **Нет зависимостей от дополнительных UI файлов**  
✅ **Простая структура проекта**  
✅ **Все стили встроены в UI файл**  
✅ **Работает без fallback механизмов**  

## 🔧 **Важные элементы для редактирования:**

- **Не меняйте имена виджетов** - код ссылается на них
- **Сохраняйте структуру панелей** (leftPanel, centerPanel, rightPanel)
- **Стили CSS встроены в UI файл**
- **После изменений перезапускайте приложение**

## 🎨 **Цветовая схема:**

- **Фон:** `#0f1619` (темно-серый)
- **Панели:** `rgba(20,28,33,0.7)` (полупрозрачные)
- **Текст:** `#dbe7f3` (светло-голубой)
- **Активные кнопки:** Зеленый/Красный/Оранжевый
- **Неактивные кнопки:** `#424242` (серый)
